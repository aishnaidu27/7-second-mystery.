# 🎮 The 7-Second Mystery

### 🔍 Observe. Remember. Solve.

A fun, interactive browser-based memory puzzle game where you have just **7 seconds** to observe clues, remember details, and solve mysterious challenges!

## ✨ Features
- ⏱️ Seven-second observation challenges
- 🧩 Multiple-choice mystery questions
- 🏆 Score tracking and personal high score
- 📈 Increasing difficulty levels
- 🔊 Sound controls
- 🌌 Dark neon-themed interface
- 📱 Responsive design for desktop and mobile
- 💾 High score saved using browser local storage

## 🎯 How to Play
1. Click **Start Game**.
2. Observe the mystery scene carefully for 7 seconds.
3. Remember the important details.
4. Answer the question by selecting the correct option.
5. Earn points and progress through harder challenges.
6. Try again to beat your highest score!

## 🛠️ Built With
- HTML5 — game structure
- CSS3 — styling and animations
- JavaScript — game logic and interactivity

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Start playing—no installation required!

## 🌐 Play Online
Play the game using the GitHub Pages link published in this repository's **Settings → Pages** section.
